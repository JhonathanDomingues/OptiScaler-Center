# Changelog

Todas as mudanças notáveis neste projeto serão documentadas neste arquivo.

O formato é baseado em [Keep a Changelog](https://keepachangelog.com/pt-BR/1.0.0/),
e este projeto adere ao [Semantic Versioning](https://semver.org/lang/pt-BR/).

## [0.1.3] - 2026-03-19

### Corrigido
- Versão sincronizada com o repositório do GitHub

## [0.1.2] - 2026-03-19

### Adicionado
- Sistema de build automatizado com GitHub Actions
- Geração de executáveis para Windows e Linux
- Workflow de release automatizado
- Arquivo PyInstaller spec para compilação
- Suporte para download de releases do OptiScaler
- Interface moderna estilo Steam com cards visuais
- Sistema de detecção automática de jogos Steam
- Análise inteligente de DLLs (DLSS, FSR, XeSS)
- Sistema de backup automático
- Gerenciamento de múltiplas versões do OptiScaler
- Tema dark moderno (#1b2838)
- Badges de tecnologia nos cards dos jogos
- Carregamento automático de imagens da Steam

### Melhorado
- Performance da detecção de jogos
- Interface do usuário mais responsiva
- Sistema de logging melhorado
- Gerenciamento de dependências

### Corrigido
- Problemas de compatibilidade no Linux
- Issues com paths relativos
- Erros de detecção de DLLs em alguns jogos

## [0.0.1] - 2026-03-01

### Adicionado
- Versão inicial do OptiScaler Center
- Estrutura base do projeto
- Sistema de detecção de jogos
- Interface básica com PyQt6
- Integração com Steam
- Sistema de backup
- Configuração via YAML
- Banco de dados SQLite
- Sistema de logging
